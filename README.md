# Max-Chat 

Веб-приложение для работы с чатами MAX через API сервиса [GREEN-API](https://green-api.com/). Интерфейс реализован на React с использованием Vite.

**Демо:** https://guromen.github.io/max-chat/

## Возможности

- Подключение к GREEN-API с помощью `idInstance` и `apiTokenInstance`.
- Получение и отображение списка чатов.
- Выбор активного чата.
- Отправка текстовых сообщений.
- Получение входящих сообщений через механизм уведомлений GREEN-API.
- Отображение отправленных и полученных сообщений в соответствующем чате.
- Автоматическое обновление данных о сообщениях посредством опроса API.
- Добавление новых чатов в список при получении сообщений от неизвестных собеседников.

## Технологии

- **React** — создание пользовательского интерфейса.
- **Vite** — сборка и запуск приложения.
- **JavaScript** — логика приложения и взаимодействие с API.
- **CSS** — оформление интерфейса.
- **Fetch API** — HTTP-запросы к GREEN-API.
- **GREEN-API** — интеграция с мессенджером.

## Запуск локально


### Установка

Клонируйте репозиторий:

```bash
git clone git@github.com:guromen/max-chat.git
cd max-chat
```

Установите зависимости:

```bash
npm install
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

Откройте адрес, который Vite выведет в терминале, обычно это `http://localhost:5173/`.

### Сборка

Для проверки production-сборки выполните:

```bash
npm run build
```

Результат сборки будет находиться в каталоге `dist`.

Для локального просмотра production-сборки можно использовать:

```bash
npm run preview
```

## Подключение GREEN-API

1. Создайте и настройте экземпляр в [личном кабинете GREEN-API](https://console.green-api.com/).
2. Получите `idInstance` и `apiTokenInstance`.
3. Откройте приложение и введите необходимые учётные данные в форме подключения.
4. После подключения приложение запросит список чатов и начнёт получать уведомления о сообщениях.

В приложении используется API-хост:

```text
https://3100.api.green-api.com
```

Для корректной работы экземпляр должен быть активен, а необходимые разрешения и настройки получения уведомлений должны быть включены в GREEN-API.
